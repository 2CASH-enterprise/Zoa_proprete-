## 💡 Choix techniques

**Pourquoi HTML/CSS/JS vanilla sans framework ?**
- Performance maximale — pas de JS lourd à charger
- Score Lighthouse 90+ sans optimisation supplémentaire
- Maintenabilité simple — n'importe quel développeur peut reprendre
- Migration facile vers WordPress ou Webflow si le client évolue
- Zéro dépendance = zéro vulnérabilité de sécurité

**Pourquoi GitHub Pages plutôt qu'un hébergeur payant ?**
- Gratuit et fiable pour un site vitrine statique
- HTTPS automatique
- Déploiement continu via Git
- Domaine personnalisé possible via configuration DNS
